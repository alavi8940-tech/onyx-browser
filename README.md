# 🧅 Onyx — مرورگر خصوصی، زیبا و بی‌ردپا

**Onyx** یک مرورگر دسکتاپ سبک و خصوصی است که با **Electron** ساخته شده و روی حریم‌خصوصیِ «بی‌حافظه» تمرکز دارد: کوکی‌ها، تاریخچه، کش و حتی پوشهٔ پروفایل به‌صورت پیش‌فرض **فقط در حافظه (RAM)** نگه داشته می‌شوند و هنگام خروج کاملاً پاک می‌شوند.

- 🧅 **پشتیبانی تور** — تب‌های تور اختصاصی با عبور از شبکهٔ Tor (خودکار یا از تورِ نصب‌شده روی سیستم)
- 🛡️ **مسدودسازی تبلیغ و ردیاب** — بیش از ۱۲۰ دامنهٔ ردیاب + فیلتر پترن/نوع منبع
- 🕵️ **سخت‌سازی حریم‌خصوصی** — حذف Referer شخص‌ثالث، ارسال DNT/GPC، غیرفعال‌سازی WebRTC (جلوگیری از نشت IP)، ارتقای خودکار HTTPS
- 🎨 **رابط شیشه‌ای فارسی** — تم‌های متنوع، پس‌زمینهٔ زنده، ساعت و میان‌برهای کامل
- ⚡ **بی‌حافظه** — همه‌چیز در RAM؛ خروج = پاک‌سازی کامل (حالت روح 👻)
- 🔄 **آپدیت خودکار** — از انتشارهای گیت‌هاب (برای نسخه‌های نصب‌شده)

## اجرای محلی (توسعه‌دهندگان)

نیازی به نصب چیزی برای بررسی کد نیست؛ فقط Node.js:

```bash
npm install      # نصب electron / electron-builder / electron-updater
npm run icon     # تولید آیکون (بدون وابستگی خارجی)
npm start        # اجرا در حالت توسعه
```

برای بسته‌بندی (فقط لینوکس روی این سیستم):

```bash
npm run dist
```

بیلد کاملِ هر سه پلتفرم توسط CI در گیت‌هاب انجام می‌شود.

## ویژگی‌های حریم‌خصوصی

| تنظیم | پیش‌فرض | توضیح |
|-------|---------|-------|
| مسدودسازی تبلیغ/ردیاب | روشن | بلاک دامنه‌ها و پترن‌های ردیابی |
| DNT / GPC | روشن | درخواست عدم ردیابی |
| حذف Referer شخص‌ثالث | روشن | جلوگیری از افشای نشانی درخواست |
| غیرفعال‌سازی WebRTC | روشن | جلوگیری از نشت آدرس IP محلی |
| ارتقای HTTPS | خاموش | تغییر خودکار http → https |
| ذخیره تنظیمات روی دیسک | خاموش | فقط تنظیمات، هیچ تاریخچه‌ای |

> تغییر تنظیم WebRTC پس از یک بار راه‌اندازی مجدد اعمال می‌شود.

## صرفه‌نظر از مسئولیت
